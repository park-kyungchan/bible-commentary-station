내 성경 파일 가져오기

한국어 14종 · 영어 9종 등 총 23개 성경 전 66권(개역개정 · 개역한글 · 새번역 · 쉬운성경 · 우리말성경 · 현대인의 성경 · 공동번역 · 바른성경 등)이 기본 내장되어 바로 대조해 읽으실 수 있습니다. 개인적으로 소장하신 다른 역본 문서 파일(메모장 파일)이 있으시면 아래에서 추가로 불러오실 수 있으며, 불러온 파일은 외부로 전송되지 않고 목사님 기기 안에만 안전하게 보관됩니다.

내 찬송가 가사 파일 가져오기

개인 소장 찬송가 가사 문서 파일을 불러오시면 찬송가 화면과 강단 큰 화면에서 인터넷 없이도 바로 보실 수 있습니다.

쉬운 사용 안내

1. 큰 글씨로 성경 읽고 비교하기

위쪽 가- / 가+ 버튼으로 본문과 주석 글자 크기를 4단계로 키울 수 있으며, 선택한 크기와 마지막 읽던 곳은 자동으로 기억됩니다. 역본 버튼을 누르면 기본 내장된 한국어·영어 23개 성경 전 66권과 개인 소장 성경 파일을 자유롭게 선택해 나란히 대조해 읽으실 수 있습니다.

2. 핵심 말씀 참고 요약과 고전 영문 주석

성경 절을 누르면 오른쪽에 핵심 말씀 참고 요약, 연결 말씀, 원어 풀이가 나타납니다. 원하실 때 고전 영문 주석 원문 불러오기 버튼을 눌러 추가 참고 자료를 보실 수도 있습니다.

3. 예배 예전 · 찬송가 · 교독문 · 예배 순서

예배 · 찬송 화면에서 사도신경, 주기도문, 성찬 예식, 축도와 645곡 새찬송가 색인, 137편 교독문, 주일 예배 순서를 한곳에서 준비하고 바로 강단 화면으로 띄울 수 있습니다.

4. 강단 화면 단축키 안내

강단 화면에서는 프레젠터 리모컨이나 키보드 오른쪽 화살표 · 스페이스바로 다음 대지, 왼쪽 화살표로 이전 대지, + / -로 글자 크기 조절, ESC로 나가실 수 있습니다.
