# KRV Data Sources

## Source and transformation

- Edition: Korean Revised Version (1961), published by the Korean Bible Society.
- Source file: `scripts/data_pipeline/sample_data/bible_1961_krv.json`.
- Acquired from: <https://raw.githubusercontent.com/bluesaurel/Korean-Bible-1961-KRV/main/bible_1961_krv.json>.
- Website asset: `prototype/bible_krv.json`, generated by `prototype/generate_web_krv.py`.
- Database import: `scripts/data_pipeline/ingest_full_krv_to_db.py` loads KRV verses and indexes them in SQLite FTS5.
- Audited counts: 66 books, 1,189 chapters, and 31,102 verses. The source-to-website transformation audit found every verse string unchanged and no leading or trailing whitespace to remove.

The Antigravity acquisition record did not check the upstream GitHub repository's license metadata. The Korean Bible Society's KRV FAQ says the edition may be used without a copyright usage fee after its property-rights protection period, while its author attribution and integrity rights must still be respected: <https://www.bskorea.or.kr/bbs/board.php?bo_table=copyright_faq&wr_id=5>. The Society's copyright notice identifies the edition as “Korean Revised Version © Korean Bible Society 1961”: <https://bible.bskorea.or.kr/copyright_notice>.

The application displays that attribution and links to the Society's notice. This provenance record does not claim that the mirror itself is an authorized distribution channel, or that every verse was independently compared with the Society's live text.

## Local-only material

The GAE collection and checkpoint are separate local research data. They are not part of the Pages asset directory and must not be staged or published with this KRV release.
